# 已完成审阅与接手时必须注意的差异

## 计划审阅结论

两份只读审阅分别检查了并行/文件所有权与验收/证据边界。采纳结果已进入执行计划：

- 通用任务边界与模型研究解耦。
- 阶段报告同时显示工程状态、研究结论、已验证边界、开放能力。
- 当前数据状态和历史覆盖分项验收。
- 前瞻协议在正式采集前冻结，测试资格不进入真实注册表。
- 每个提前交付版本都完成适用恢复验收。
- 子代理须提供 mock/fixture/故障注入清单、测试变更账与真实运行计数。
- 新实验不能修改已冻结协议、反复看过测试集后再冒称样本外。

计划结构已用程序检查任务覆盖、默认顺序和并行写文件白名单。该检查不是实际仓库实现的通过证据。

## 仓库 AGENTS 的冲突清单

原文件为固定基线的一部分，本包没有修改它：

1. 有特定 provider/model 表和 OpenCode 优先/持续使用条款；新环境不一定具有这些能力，本轮用户选择的是子代理执行、主模型验收。不得据旧文本自行配置账号或启动 CLI。
2. 有 `--auto` 跳过等待的文字；不能用于跳过当前所需授权。
3. 有固定审查层数与 Git 回退建议；当前 enough 强调按风险与证据验收，保护用户已有工作，禁止无授权回退提交。
4. CSV、不引入 pyarrow/parquet 的规则仍有效，除非 D01 对隔离研究环境例外得到批准。
5. 中文、类型注解、维护性、前端真实验证及配置验证等未冲突规则继续遵守。

主控 PRE0 应显式报告差异；必要的仓库规范协调作为最小受控变更提出，不默默改原文件，也不以“旧规则优先”为由突破当前用户的授权边界。

## 项目关键风险（不是已修复清单）

- 模拟路径不能伪装真实模型分布或校准概率。
- 缺信号不等于 HOLD，无看多证据不等于 SELL。
- 缓存更新时间不等于行情时效。
- 使用当前成分股回溯不能冒充历史无偏股票池。
- 回测不能用预测价成交，收盘后信号不能按同一收盘价成交。
- 测试容许 error 返回，不能证明真实成功链已运行。
- 旧默认启动、配置保存、模型生命周期和取消边界需要按任务修复。

完整来源在总计划的固定提交链接中；新主模型应在实际修改前再次核对源码。
